# WebDev_Project_Group_B_Baraghin_Cristi
Lab work week 3, creating site for Lucas Snow.

This website is a simple winter adventure landing page for Powder Chase Adventures, a snowboarding brand focused on fresh powder, thrilling mountain experiences, and the excitement of exploring top ski and snowboard trails. The home page introduces the brand with a story about an intense night ride in deep snow, while the About page explains the mission and identity of the company.
